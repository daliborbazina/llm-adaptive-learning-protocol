# Examples

This directory contains examples showing what the prompt produces and what information can be carried from one test to the next.

The examples should not contain real names, personal information, course information, or private test history.

## Files

### `initial-test.pdf`

An example of a first test created without previous mistake history.

### `next-test.pdf`

An example of a later test created after the user made several example mistakes.

It should show that some weak areas return while unrelated correct answers are not simply repeated.

### `state-example.txt`

A small example of the information the prompt keeps between tests.

Example:

```text
SKILL:
Personal pronouns — Dative

STATUS:
STABILIZATION

ERROR:
er instead of ihm

NEXT CHECK:
after 3 days
```

The example state is only for demonstration. It should not contain a real user's learning history.
